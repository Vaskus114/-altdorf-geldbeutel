# Core-Beschreibungen

Datenbasis: **Warhammer Fantasy Roleplay, First Edition - Core Rulebook**.

Enthalten:
- 133/133 Core-Skills mit Beschreibung/Regelwirkung
- 155/155 Core-Zauber mit kompakter Beschreibung/Wirkung

Die Beschreibungen werden im Charakterbogen über aufklappbare Bereiche angezeigt. Bei bestehenden Charakteren werden fehlende Beschreibungen von Core-Einträgen beim Laden automatisch aus der Datenbank ergänzt.

Alle Beschreibungsfelder bleiben frei editierbar. Dadurch können Hausregeln, Korrekturen oder kampagnenspezifische Ergänzungen weiterhin eingetragen werden.
