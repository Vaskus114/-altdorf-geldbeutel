# Altdorfer Geldbeutel

Eine installierbare Offline-Web-App zur Verwaltung mehrerer Charakter-Geldbeutel für Warhammer Fantasy Roleplay.

## Funktionen

- mehrere Charaktere mit getrennten Geldbeuteln
- Goldkronen, Schilling und Pfennige
- automatische Umrechnung und Wechselgeld
- Einnahmen, Ausgaben und Buchungsverlauf
- Backup und Wiederherstellung einzelner Charaktere
- eigens erstellte, abgenutzte Münzgrafiken und Materialtexturen
- lokale Speicherung auf dem jeweiligen Gerät
- offline nutzbar und auf iPhone sowie Android installierbar

Die App überträgt keine Charakter- oder Buchungsdaten an GitHub. Alle Einträge bleiben im lokalen Browser-Speicher des jeweiligen Geräts.
